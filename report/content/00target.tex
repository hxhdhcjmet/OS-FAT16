\section{实验目的}
\begin{itemize}
    \item 任务一:实现一个简单的类FAT-16文件系统,掌握FAT文件分配表的基本原理、磁盘空间划分方式以及文件目录管理的基本方法。
    通过将内存数组模拟为硬盘,深入理解文件系统中超级块、FAT表、目录区和数据区的组织结构,以及文件的创建、打开、读写、关闭和删除等核心操作的实现机制。
    \item 任务二:在任务一的基础上,实现多个进程同时访问文件和目录的功能,掌握读者-写者问题的经典解法及其在文件系统中的应用。
    通过引入进程控制块(PCB)、信号量和互斥锁等同步机制,理解并发环境下文件系统资源保护的设计思路,加深对操作系统并发控制理论的认识。
\end{itemize}
